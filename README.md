# Projetos e Exercícios Python

Repositório dedicado ao meu aprendizado e desenvolvimento em **Python**, reunindo exercícios práticos, desafios de programação e pequenos projetos desenvolvidos durante minha jornada de estudos.

O objetivo deste repositório é consolidar conhecimentos, desenvolver o raciocínio lógico e adquirir experiência prática com a linguagem Python e suas bibliotecas.

## Objetivos

- Desenvolver o raciocínio lógico e a resolução de problemas.
- Aprender e praticar os fundamentos da linguagem Python.
- Compreender os conceitos de Programação Orientada a Objetos (POO).
- Desenvolver interfaces gráficas utilizando Kivy.
- Trabalhar com funções, classes, métodos e estruturas de dados.
- Construir uma base sólida para projetos mais complexos.

## Como executar os projetos

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Entre na pasta do projeto

```bash
cd ProjetosKivy
```

### 3. Crie um ambiente virtual

```bash
py -m pip install virtualenv
py -m virtualenv kivy_project
```

### 4. Ative o ambiente virtual (Windows)

```cmd
kivy_project\Scripts\activate.bat
```

### 5. Instale o Kivy

```bash
python -m pip install --upgrade pip
python -m pip install "kivy[base]"
```

### 6. Execute um exercício

```bash
python calculadora.py
```

**Observação:** alguns exercícios podem utilizar apenas Python, sem necessidade de instalar o Kivy.
